# Adversarial pre-submission review

Date: 2026-10-30. Target: IEEE TDSC. Current decision: **NO-GO**.

This review asks whether the evidence is strong enough for the journal, not only
whether the PDF is internally consistent.

## 1. Correctness of results — open

The CRC equation, monotonicity direction and pointwise domination argument pass
internal code-and-claim review. A unit test that incorrectly checked
`P(L > delta)` instead of `E[L]` was repaired. This does not verify the reported
`theta = 0.0602` or `tau_hat = 0.0447` from the real calibration runs.

The checkout does not contain the three reported matrices. A new exporter now
produces `crc_calibration.csv`, and `recompute_crc_independent.py` reconstructs
the run-level loss curve without importing the project CRC or predictor modules.
It must be run on the analysis host and its output checked by another researcher.

Pass criterion: an external auditor obtains the same threshold and corrected
risk from the ledger, verifies the 20 run identifiers against manifests, and
finds no evidence against exchangeability of the declared ID pool and a future
run generated by the same mechanism.

## 2. Scientific novelty — provisionally passes, priority claim removed

PILOT (NSDI 2026) is execution-based recovery validation and is now treated as
the closest prior system. The defensible distinction is narrower: verified
common-state execution of all candidate actions plus measurement of residual
pairwise dispersion. The paper no longer claims to originate recovery preview.

Pass criterion: no full-text comparator is found that already combines
common-state multi-action execution with an empirical resolution audit. A
different engineering mechanism alone is not sufficient novelty.

## 3. Experimental strength — mixed

The testbed supplies 8,118 branches across three mechanisms, but it remains one
emulated deployment. RCAEval adds an independent system and a different source
of uncertainty; its full-five estimate overlaps the smaller subsets and is a
descriptive reference, not independent ground truth. The manuscript now says
this and does not infer a minimum replication count.

Pass criterion: all heterogeneity and sensitivity claims recompute from the
published derived data, and no conclusion depends on treating overlapping
subsets as independent validation.

Internal status: adversarial inspection found that epsilon-Diagnosis omitted the
true service from 352/375 rankings. Pooled results that mapped those absences to
zero were therefore withdrawn. The retained BARO--N-Sigma results now have a
second implementation using only Python's standard library. It enumerates all
`5^5=3125` paired bootstrap resamples per configuration rather than drawing
4,000 Monte-Carlo resamples and reproduces `8/375`, `43/75`, and all revised
subset figures exactly. Thus the retained count is not a random-seed or
Monte-Carlo artifact. This is an independent implementation, but it was still
run inside the same project and does not replace an external replication.

The primary scoring pass has now also been reconstructed in a clean Python 3.12
environment from the pinned public dataset revision and RCAEval 1.9.0. Its 375
JSON lines match the retained source byte-for-byte (SHA-256
`b542851fb79c4848295557370e07d11ad7b6652432dfdaa5902873d2e51846e4`).
This closes the internal RCAEval rerun, including the 352 epsilon-Diagnosis
absences; it still does not turn an author/AI rerun into independent external
replication.

## 4. Dependability consequence — present but not yet independently reproducible

Five D4 decision states provide the concrete failure case requested by an
adversarial reviewer: `s03-a14`, `s27-a02`, `s27-a08`, `s33-a14`, and `s39-a14`.
The structural model predicts that rerouting helps; executing the alternative
shows that it harms. The observed/predicted contrasts are respectively
`-0.1430/+0.1534`, `-0.1737/+0.0181`, `-0.1386/+0.2480`,
`-0.1234/+0.1559`, and `-0.1295/+0.1354`. The operational consequence is a
wrong-direction recovery choice caused by imputing nominal capacity to an idle,
degraded path. Fork-and-replay exposes the error because telemetry from the path
in use cannot identify the unused path's capacity.

This establishes why multi-action execution matters more directly than a generic
claim about repeated measurements. It is already in the main paper and
Supplement, so no conceptual rewrite is required. It remains evidence only after
`d45-matrix-v1/structural.csv` and the underlying objective rows are published
and independently recomputed.

## 5. Reproducibility and submission readiness — fails

The published Zenodo record `10.5281/zenodo.23321904` was queried through its API
on 2026-10-30. It contains one file, `Dev-Nikita/csc-iot-0.3.zip` (764,856
bytes). Inspection found the old `RESULTS.md` and `EXPERIMENT_PROTOCOL.md`, but
no `jobs.csv`, RCAEval `results.jsonl`, replication-sensitivity script/output,
CRC ledger, `CRC_AUDIT.md`, or data-package checksums. Version 0.3 therefore does
not reproduce the current paper.

The former packaging script also overclaimed that every result was recomputable
from `jobs.csv`; those rows do not contain predictor features, split membership,
predicted risk or uncertainty. The package definition now requires the primary
matrix's structural and decision outputs, a complete CRC calibration ledger and
an independently reconstructed curve; it also includes the RCAEval cases and
new analysis. It explicitly states that predictor refitting still requires the
retained branch records.

Pass criterion: build the package on the analysis host, verify every checksum in
a clean directory, execute the independent CRC reconstruction and RCAEval
analysis there, upload a new Zenodo version, and confirm the public download.
The paper and supplement must then cite the DOI of that exact version.

## Decision rule

TDSC submission becomes eligible for GO only when sections 1 and 5 pass under a
person other than the author or this AI-assisted workflow. Novelty and the
dependability consequence are presently credible, but they do not compensate
for an archive that cannot reproduce the current results.
