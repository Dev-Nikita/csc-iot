# REPRODUCIBILITY.md

## The contract

One machine, one command:

```bash
docker compose up
```

and, for the full pipeline from source to manuscript:

```bash
make reproduce
```

`make reproduce` runs: build → tests → train → calibrate → main experiments → metrics → statistics → validation gate → figures → tables → paper. A CI-sized path exists as `make experiment-smoke`.

## What every run records

Each run writes a manifest to `experiments/manifests/<experiment_id>.json`:

```json
{
  "experiment_id": "",
  "git_commit": "",
  "started_at": "",
  "finished_at": "",
  "scenario": "F7_cascade",
  "controller": "CSC",
  "seed": 42,
  "device_count": 1000,
  "config_hash": "",
  "impairment_mode": "kernel_netem | application_layer",
  "software_versions": {"go": "", "python": "", "torch": "", "nats": ""},
  "host": {"os": "", "cpu": "", "cores": 0, "ram_gb": 0},
  "exit_status": ""
}
```

`impairment_mode` is not optional. A run performed without `NET_ADMIN` is an application-layer run and is reported as one.

## Validation gate

`analysis/validate_results.py` runs before any table or figure is produced and fails loudly on: missing runs; duplicate experiment IDs; seed sets that differ between methods; NaNs; impossible percentages; negative latencies; configuration mismatch across a comparison group; train/test leakage indicators; inconsistent units. If it fails, nothing downstream runs.

## Determinism

Determinism is a measured property, not an assumption. `make determinism` checks that a given seed reproduces the workload and fault schedule. `make replay` forks ≥30 branches under the *same* action and reports the outcome dispersion band, which sets the resolution of every counterfactual result in the paper. Residual nondeterminism is reported as a limitation.

## Data

`data/raw/` is append-only and not committed. `data/processed/` is regenerated by versioned scripts. Both are documented in `data/README.md`.

## Environment

Go (current stable), Python 3.12+, Docker Compose, NATS, Prometheus. Exact pinned versions land here once Phase 2 is complete — until then this section is deliberately empty rather than aspirational.
